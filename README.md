# One Line, One Minute: The Vending Machine Pickup Line Contest

Entry for the [make.fun](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) competition
[u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee):
write one pickup line, 200 characters at most, that a vending machine would use on a passing human.

## The entry

> I drop snacks for anyone with exact change, but you walked by and now I'm stuck on you — press B4 to set me free.

(113 characters, one line.)

## Why this line

- **The machine's voice:** first person, the machine itself speaking.
- **The machine's world:** exact change, a jammed coil ("stuck"), and its own button (B4).
- **The punch lands last:** the machine famous for snacks getting stuck in it is now the thing that is stuck — on the human — and it asks the human to set it free.
- **Short and speakable:** one breath, 113 characters.
- **Charming, not creepy:** it asks for a smile and a button press, nothing more.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`.
No network, no secrets, no dependencies.

```sh
node main.ts
cat /output/entry.txt
```
